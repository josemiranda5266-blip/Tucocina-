# Alcance del MVP de CO-Cocina

## Funcionalidades Incluidas en el MVP
- [x] Home con catálogo, recetas populares y recientes
- [x] Buscador determinístico por palabras clave y filtros por categoría/plataforma
- [x] Detalle de video con reproductor embed oficial
- [x] Autenticación con Google Sign-In mediante Firebase Auth
- [x] Guardado y eliminación de Favoritos en Firestore vinculado a la cuenta del usuario
- [x] Panel Administrativo con métricas, lista de videos, cambio de estado y borrado
- [x] Importación administrativa por URL con verificación SSRF y extracción de metadata
- [x] Envío y gestión de reportes de videos rotos o inapropiados
- [x] Reglas de seguridad estrictas en Firestore y backend Express

## Funcionalidades Excluidas del MVP
- Chatbot o interfaz conversational
- Búsqueda semántica o recomendaciones por IA
- Colecciones complejas, listas personalizadas o funciones sociales
